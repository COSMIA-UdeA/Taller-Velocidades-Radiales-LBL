# Un ejemplo práctico

Aquí mostramos un ejemplo práctico y "de la vida real" de lo que se puede lograr utilizando LBL y RadVel.
Estos son algunos de los resultados obtenidos con mediciones del instrumento MAROON X de Gemini North, Hawái, observando el sistema TOI-233: una estrella de 0.37 masas solares que está siendo orbitada por dos planetas en _near-resonance_. Uno posiblemente siendo una super-Tierra y otro un sub-Neptuno.
